**美搭AI数字人(xjaigc)** 是一款功能强大的AI数字人SaaS系统，支持私有化部署。它集成了业界领先的AI模型，为个人和企业用户提供一站式数字人解决方案。

我们的愿景是让每个人都能轻松拥有和使用自己的数字分身。

## ✨ 核心功能

### 🎤 AI声音合成
- **文字转语音（TTS）**：支持多种音色，实时合成自然流畅的语音
- **声音克隆**：基于5-30秒音频样本，克隆任意说话人声音
- **公共配音库**：精选默认音色一键选择，无需上传即可体验高质量配音
- **批量语音生成**：支持文本批量处理，提高生产效率

### 🎭 数字人生成
- **唇形同步视频**：AI驱动的精准唇形匹配技术
- **表情动画**：丰富的面部表情和动作库
- **高清输出**：支持4K分辨率视频生成

### 📺 直播功能
- **实时数字人直播**：AI数字人实时互动直播
- **语音驱动**：声音实时转换为数字人动作
- **多平台推流**：支持各大直播平台

### 🔐 用户系统
- **安全登录**：RSA加密+验证码双重验证
- **自动登录**：本地SQLite安全存储，支持自动登录
- **游客模式**：无需注册即可体验部分功能
- **数据同步**：云端用户数据与本地缓存智能同步

- **资源分类**：支持本地资源、服务端资源、自定义资源三种来源分类

### 创建新视频模板步骤
1. 在 `public/defaults/templates/` 下创建目录结构
2. 添加视频文件（推荐.mp4格式）和缩略图（.jpg/.png）
3. 创建 `metadata.json` 配置文件，包含基本信息
4. 系统自动扫描加载，支持热更新

### 真实资源加载
系统现已完全移除mock数据，直接加载`public/defaults/templates/`目录下的实际模板文件：

```
public/defaults/templates/
├── business/
│   └── marketing-campaign/
│       ├── metadata.json      # 模板配置文件
│       ├── kaihuang.mp4       # 实际视频文件 (13MB)
│       └── kaihuang.jpg       # 缩略图文件 (15KB)
└── [其他分类]/
    └── [模板名称]/
        ├── metadata.json
        ├── video.mp4
        └── thumbnail.jpg
```

### 创建视频模板步骤
1. **准备资源文件**:
   - 视频文件: 720×1280分辨率，H.264编码
   - 缩略图: JPG格式，建议9:16比例

2. **创建目录结构**:

3. **编写metadata.json**:

4. **放置文件**:

   ```
   ├── metadata.json
   ├── [视频文件名].mp4
   └── [缩略图文件名].jpg
   ```

5. **验证加载**:
   - 重启应用自动扫描新模板
   - 在模板中心查看加载结果

### 🗄️ SQLite用户存储架构

#### 数据库设计
- **用户信息表(user_info)**: 存储用户基本信息(用户名、邮箱、头像、性别等)
- **用户会话表(user_session)**: 存储AES加密token和登录状态，支持7天自动登录
- **用户偏好表(user_preferences)**: 存储用户个性化设置(主题、语言、自动登录开关等)

#### 业务流程
- **登录成功**: 自动保存用户信息+加密会话+偏好设置到SQLite
- **应用启动**: 检查SQLite有效会话，支持无感知自动登录
- **退出登录**: 清除SQLite会话信息，确保安全性
- **网络异常**: 使用SQLite缓存维持基础功能

#### 安全特性
- **AES加密**: 使用crypto-js对token进行AES对称加密存储
- **过期管理**: 7天token过期机制，自动清理过期会话
- **索引优化**: 为用户ID建立索引，提升查询性能
- **错误处理**: 完整的异常处理和降级方案

#### 技术集成
- **后端**: UserDatabase类完整CRUD + 11个IPC接口
- **前端**: 集成到Vuex用户Store的Login/Logout/CheckAutoLogin
- **存储**: 文件级持久化，关闭应用后数据不丢失

## 📖 使用说明

### 🔐 用户登录使用指南

#### 1. 注册和登录
1. **首次使用**：点击右上角头像 → 选择"注册账号"
2. **已有账号**：点击右上角头像 → 输入用户名密码 → 输入验证码 → 登录
3. **游客模式**：点击"游客登录"可免注册体验基础功能

#### 2. 智能自动登录
- **自动登录**：用户正常关闭应用后，下次启动自动恢复登录状态
- **手动退出**：用户主动点击"退出登录"后，下次启动不会自动登录，需要手动重新登录
- **数据安全**：所有会话信息加密存储在本地SQLite数据库，采用AES-256加密
- **过期管理**：Token有效期30天，过期后自动清理

#### 3. 用户中心功能
- **个人资料**：查看和编辑用户基本信息，包括头像、用户名、邮箱等
- **VIP服务**：查看VIP特权说明，升级VIP账户享受更多服务
- **使用统计**：实时显示生成任务数、使用时长、成功率等数据
- **个人设置**：自定义界面主题、语言、通知设置等个人偏好

#### 3.1 用户中心访问方式
- **登录后点击头像**：直接跳转到本地用户中心页面
- **侧边导航设计**：采用与数字人、工具箱相同的左侧导航布局
- **多标签切换**：个人资料、VIP服务、使用统计、个人设置四个功能模块
- **响应式设计**：支持不同屏幕尺寸，保持良好的用户体验
